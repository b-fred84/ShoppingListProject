# Shopping List App

A simple web application built with vanilla JavaScript that allows users to add, edit, delete, filter, and persist items in their browser. This project demonstrates DOM manipulation, event handling, and localStorage usage. Built as part of a beginner JavaScript course

## Features

- Add new items to the list  
- Edit existing items  
- Delete individual items  
- Clear all items at once  
- Filter/search items in real-time  
- Persist items using localStorage  

## Technologies Used

- **JavaScript (ES6+)** – Core language
